## What it is

Querify can monitor patterns in your connected data and surface **insights** when something notable changes — for example spikes, drops, or trends against recent history.

## Where to find them

Open the **Insights** area from the main navigation. Each card shows a short explanation and a path to the underlying data.

## How to use them

Treat insights as a starting point. Open the related chat or rerun the suggested question with different time ranges.
