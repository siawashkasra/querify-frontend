## Chat threads

Each thread keeps your questions and answers in order. Switch connections from the header when you have more than one database.

## Result cards

After a successful answer you typically see:

- **Summary** — Short text in plain English
- **Data** — Table or chart when it fits
- **SQL** — Expand to see the exact statement. Copy it to verify in your own tools.
- **Context** — Which tables were used and any assumptions

Use **Ask again** or edit the prompt to refine the question if the first answer was not quite right.
